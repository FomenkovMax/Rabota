# Агент сравнения розничных продуктов банков в ЛНР

Системный промпт для ИИ-агента с браузером. Агент собирает условия всех продуктов для физлиц у Сбера, ВТБ, ПСБ и Т-Банка с привязкой к ЛНР, сравнивает конкурентов со Сбером и выдаёт Excel, HTML- и Streamlit-дашборды, CSV для BI и отчёт для руководства.

## Файлы

| Файл | Что это |
|---|---|
| `system-prompt.txt` | Промпт целиком — копируй как есть |
| `README.md` | Эта инструкция и готовые стартовые сообщения |

## Что нужно от платформы

Агенту нужны четыре вещи:

1. **Браузер с кликами** — выбрать регион на сайте, поставить галочку «новые регионы» в калькуляторе. Обычного веб-поиска мало: он видит страницы такими, какими их отдают по умолчанию (чаще всего — с условиями для Москвы).
2. **Доверие к сертификатам Минцифры.** Сайты Сбера, ВТБ, ПСБ и Т-Банка работают на сертификатах НУЦ Минцифры (Russian Trusted Root CA, проверено 05.10.2026). Браузеры с международным набором сертификатов им не доверяют, а облачные агенты работают именно на таких. Поэтому облачный агент, скорее всего, увидит ошибку сертификата. Рабочие варианты:
   - агент, который работает в твоём браузере на ПК с установленным сертификатом Минцифры (инструкция — [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt));
   - локальный Python-агент на таком же ПК.

   Проверено 05.10.2026 в облачной песочнице: с установленным корнем Минцифры сами сайты отвечают, но браузер всё равно получает 502 от прокси среды. Подробности — в [runs/2026-10-05_test-dostupa/run_log.md](runs/2026-10-05_test-dostupa/run_log.md).
3. **Выполнение кода** — чтобы собрать xlsx, html и csv.
4. **Загрузка файлов** — чтобы прикладывать историю прошлых срезов.

## Настройка

0. **Тестовый запуск.** Попроси агента открыть sberbank.ru, vtb.ru, psbank.ru и tbank.ru и выбрать на каждом регион ЛНР. Если сайты не открываются из-за сертификата, этот агент не подойдёт — варианты в пункте «Доверие к сертификатам Минцифры» выше.
1. Вставь `system-prompt.txt` в инструкции проекта или агента. Если поле ограничено по длине — загрузи файл в базу знаний проекта, а в инструкции напиши: «Работай строго по инструкции из файла system-prompt.txt».
2. При необходимости поправь блоки `<parameters>` (банки, пороги, город) и `<scenarios>` (суммы и сроки типовых кейсов).
3. Запускай стартовыми сообщениями ниже.

## Как работает конвейер

Полный розничный блок по четырём банкам — это сотни значений, в одну сессию агента он скорее всего не поместится. Поэтому работа идёт по шагам:

```
БЛОК × 6 запусков   →   СБОРКА              →   ОБНОВЛЕНИЕ раз в неделю
(сбор по блокам)        (дашборды и отчёт)      (изменения и алерты)
```

После каждого запуска сохраняй папку `bi/` и файл `site_playbook.csv` — это память конвейера:

- `bi/` — история всех срезов: CSV-таблицы, из которых строятся дашборды и BI;
- `site_playbook.csv` — как на каждом сайте выбрать ЛНР. Со второго запуска агент работает быстрее и одинаково, поэтому срезы можно сравнивать между собой.

Прикладывай их (папку `bi/` — архивом `bi.zip`) к следующему запуску. Если платформа умеет запускать задачи по расписанию — поставь туда ОБНОВЛЕНИЕ раз в неделю.

## Стартовые сообщения

**1. Первый запуск**

```
Режим: БЛОК: Сбережения
Это первый запуск. Начни с этапа 1 (присутствие банков в ЛНР и поиск других банков), затем вклады и накопительные счета.
```

**2. Остальные блоки** — по одному за запуск: Карты → Кредиты → Ипотека → Повседневный банкинг + Каналы и инфраструктура → Инвестиции, пенсии, страхование + Сегментные предложения.

```
Режим: БЛОК: Карты
Прикладываю bi.zip и site_playbook.csv с прошлых запусков — дополни их.
```

**3. Сборка дашбордов и отчёта**

```
Режим: СБОРКА
Прикладываю bi.zip и site_playbook.csv. Проверь качество данных и собери полный комплект: Excel, HTML-дашборд, app.py, CSV для BI и отчёт для руководства.
```

**4. Еженедельное обновление**

```
Режим: ОБНОВЛЕНИЕ
Прикладываю bi.zip и site_playbook.csv со среза от ДД.ММ.ГГГГ. Обнови данные, начни резюме с алертов и пересобери все выходы.
```

## Что получится на выходе

| Файл | Для чего |
|---|---|
| `lnr_retail_{дата}.xlsx` | Excel: сводка со светофором, продуктовые линейки, вкладки по блокам с графиками, gap-анализ Сбера, изменения, источники |
| `dashboard_{дата}.html` | Интерактивный дашборд одним файлом — открывается в браузере |
| `app.py` | Streamlit-дашборд с динамикой по всем срезам. Нужен Python и пакеты, которые агент перечислит в начале файла; запуск — `streamlit run app.py` |
| `bi/*.csv` + `bi/data_dictionary.md` | Данные для Power BI, DataLens или Superset |
| `report_{дата}.docx` | Отчёт для руководства на 1–2 страницы |
| `site_playbook.csv`, `run_log.md` | Память конвейера и журнал запуска |

## Ограничения

- **Сайт может не открыться у агента.** Главная причина — сертификаты Минцифры (см. «Что нужно от платформы»). Агент сообщит об этом сразу, на этапе подготовки, а не в конце прогона.
- **Только публичные данные.** Агент не обходит капчи, не входит в личные кабинеты и не подаёт заявки.
- **Звонок и визит в офис агент не заменит.** Такие пункты попадут в раздел отчёта «Нужна ручная проверка».
- **Рабочий контур.** Перед тем как использовать внешний ИИ-сервис для рабочих задач, сверься с правилами ИБ банка. В агента — только публичная информация.
- **Стартовые факты в промпте** (кто из банков работает в ЛНР, условия ипотеки 2 %) агент использует только как подсказку и перепроверяет на сайтах банков. Откуда они взяты — в разделе ниже.

## Что дальше

Из-за сертификатов самый надёжный вариант — локальный Python-агент (Playwright + LLM) на ПК с сертификатом Минцифры. Он же даёт конвейер «по кнопке»: запуск по расписанию без ручного прикладывания файлов. Этот промпт станет ядром его LLM-модуля.
