# 🧠 ЧГК-тренажёр (Telegram-бот)

Соло-тренировка по «Что? Где? Когда?»: вопрос → **60 секунд** с обратным отсчётом → ответ → оценка (✅ / 🟡 ½ балла / ❌) → **разбор логики**.

## Как это устроено
| Файл | Что делает |
|---|---|
| `bot/main.py` | Telegram-логика: таймер, кнопки, цикл вопроса |
| `bot/judge.py` | Оценка ответа: точное совпадение → Claude → запасной fuzzy-режим |
| `bot/generator.py` | Генерация **оригинальных** вопросов: «автор» пишет, «критик» проверяет факты и однозначность |
| `bot/storage.py` | База вопросов (`questions.json`) и статистика (SQLite) |
| `bot/cards.py` | Картинки с волчком (Pillow): `python -m bot.cards` |

## Быстрый старт (локально)
```bash
cd chgk_bot
pip install -r requirements.txt
cp .env.example .env     # впиши BOT_TOKEN, ANTHROPIC_API_KEY, ADMIN_ID
python -m bot.main
python -m pytest -q      # тесты
```

## Деплой на VPS одной командой (Ubuntu, от root)
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/FomenkovMax/Rabota/claude/gracious-lovelace-w0b4kc/chgk_bot/deploy/setup.sh)
```
Скрипт поставит Docker, скачает проект, спросит токен/ключи (скрытый ввод), запустит бота и проверит ключ. Повторный запуск того же скрипта обновляет бота (твой `.env` и данные сохраняются).

## Деплой вручную (VPS с Docker)
```bash
git clone <репозиторий> && cd Rabota/chgk_bot
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```
Вопросы и статистика лежат в volume `chgk_data` и переживают обновления.

## Наполнение базы
- В Telegram, от админа: `/gen 5 история` — Claude напишет 5 вопросов, критик отсеет слабые, остальные попадут в базу.
- Вручную: добавь объект в `questions.json` (поля `text`, `answer`, `accepted`, `explanation`, `tags`, `difficulty`).
- ⚠️ Генерируемым вопросам стоит **давать быстрый взгляд человека**: LLM может ошибаться в фактах. Критик снижает риск, но не убирает его.
- Три демо-вопроса в `seed_questions.json` — лёгкие, для проверки работы.

## Командная игра (спортивное ЧГК)
Добавь бота в групповой чат команды и отправь `/game` (можно `/game 2x10` — 2 тура по 10 вопросов; по умолчанию 3×12 = 36, как в пакетах).
- 60 секунд на обсуждение (лошадка с отсчётом), потом **капитан** сдаёт ответ: реплаем на сообщение бота или `/o ответ` (20 сек).
- Очко даётся только за верный ответ («почти» не считается), после каждого тура — итог тура, в конце — итог игры.
- `/captain` ответом на сообщение игрока передаёт роль, `/stop` заканчивает игру, `/stats` — статистика команды.
- Чтобы играть мог любой участник группы: отправь в группе `/myid`, возьми «ID этого чата» и впиши в `ALLOWED_CHATS` в `.env`.

## Статистика вопросов и разбор по шагам
- После ответа бот показывает, какую долю игроков/команд взял вопрос («Этот вопрос берут 63%»). Доля считается по **первой попытке** каждого.
- Вопросы, которые при ≥6 ответах берут почти все (>90%) или почти никто (<10%), скрываются из игры. Админу: `/qstats` — самые лёгкие и сложные.
- Кнопка «🧩 Разбор по шагам» разбирает вопрос цепочкой «зацепка → вывод» с пометкой приёма (логика, гипотеза, ассоциация, перебор, знание). Строится по комментарию автора, без новых фактов, и кэшируется.

## Настоящие вопросы ЧГК (iqga.me)
В `bot/iqga_selected.json` лежат **только ID** отобранных вопросов (145 шт. из 5 пакетов сезона 2025/26). Тексты в репозитории не хранятся: на сервере команда скачивает их с сайта (по одному запросу раз в 1,5 с) вместе с автором, пакетом и ссылкой:
```bash
docker compose exec chgk-bot python -m bot.import_iqga
docker compose restart
```
Это материалы авторов вопросов: для личной тренировки команды. Не публикуйте их и не используйте в платных продуктах без разрешения авторов. Доступ к боту можно закрыть: `ALLOWED_IDS=id1,id2` в `.env`.

## Анимация таймера
Пока идёт минута, бот показывает зацикленную анимацию `assets/horse.mp4` — золотая лошадка бежит по кругу вокруг стола (6 сек, без звука, бесшовная петля), а отсчёт обновляется в её подписи. Если файла нет, бот показывает обычный текстовый таймер. Исходный кадр и «сырое» видео лежат в `art_src/`.
