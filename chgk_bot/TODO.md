## ⏳ Вернуться к Э3: ассеты Higgsfield (обязательно!)
- На момент Э3 на аккаунте Higgsfield было **0 кредитов (тариф free)** — ничего не генерировали.
- Когда появится баланс: составить смету по `assets/ASSET_SPEC.md`, получить отдельное «да» от Максима на каждый набор (бюджет ≤1000 кр.).
- Рекомендация: Recraft V4.1 для иконок и фона, `remove_background` для слоёв, видео награды — в последнюю очередь.
- Звуки `sfx.*.mp3`: Higgsfield-audio или CC0 (скачивать должен сам Максим).
- Код под ассеты уже готов: файл по ID в `webapp/public/assets/` подхватывается без правок.
