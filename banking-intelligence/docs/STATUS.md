## Что НЕ закрыто
1. **Нет данных Сбербанка (эталона).** Сайт закрыт WAF (`user_blocked`), обход не выполняется. Путь — ручной импорт страниц: `docs/sber-manual-import.md`. После получения файлов нужен адаптер Сбера (пишется по реальной вёрстке).
2. **Доступность продуктов в ЛНР не подтверждена ни у одного продукта.** Страницы ПСБ/ВТБ не содержат утверждений о доступности (ЛНР упомянута только в телефоне поддержки). Подтвердить можно по официальному документу банка либо через AI-извлечение с проверенной цитатой.
3. **AI-извлечение (этап 3) не проверено на реальной модели** — только на подставном клиенте. Нужны решение об отправке публичных текстов во внешний API, `OPENAI_API_KEY`, `AI_MODEL`, `AI_ENABLED=true` (`docs/ai.md`).
4. **Не запускались:** сборка Docker-образа и compose-стека, GitHub Actions (`.github/workflows/banking-intelligence.yml`), реальный Telegram (бот, рассылка, отправка файлов).
5. Генбанк (401/403) и ЦМР (нет подтверждённых страниц продуктов) — данных нет.

## Известные ограничения расчётов
Простой процент по номинальной ставке сайта, до налогов, без капитализации; ставки на сайтах — диапазоны, поэтому результат — интервал. Условия ВТБ (срок/пополнение) без AI не извлекаются, часть вкладов ВТБ исключается из сценариев с указанием причины.

## Что нужно от владельца (в порядке пользы)
1. Страницы Сбера (вклады, накопительные счета; публичные), сохранённые из браузера — инструкция в `docs/sber-manual-import.md`.
2. Решение по AI: можно ли отправлять публичные тексты страниц ПСБ/ВТБ во внешний API; ключ и название модели; затем пробный прогон на 3–5 страницах и ручная сверка цитат.
3. `BOT_TOKEN`, свой Telegram ID, `POSTGRES_PASSWORD` — для первого реального запуска `docker compose up --build`.
4. Сверить отпечаток сертификата Минцифры (`certs/README.md`).
5. Подтвердить домены и присутствие банков в ЛНР в `config/banks.yaml` (сейчас все флаги `false`).
