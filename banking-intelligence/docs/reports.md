# Отчёты (этап 5)

`bankintel report --out reports/` или команда бота `/report` → четыре файла из **одного** набора данных:

| Формат | Что внутри | Графики |
|---|---|---|
| HTML | самодостаточный (Plotly встроен, работает без интернета), 5 сценариев, каталог, источники | интерактивные Plotly |
| PDF | A4 альбомный, колонтитулы с номером набора данных | встроенный SVG (без браузера) |
| PPTX | 13 слайдов: главное, охват, 5 сценариев, каталоги по банкам, методика | нативные редактируемые диаграммы PowerPoint |
| XLSX | сводка, охват, сценарии (числа, не текст), исключённые, вклады, счета, источники, график | диаграмма Excel |

## Единый проверенный набор данных
`reports/dataset.py: build_dataset` собирает JSON-совместимый словарь, `validate_dataset` проверяет его до рендеринга и **отказывает**, если:
- нет ни одного продукта; у продукта нет ссылки на сохранённый документ или даты проверки;
- название/ссылка похожи на тестовые данные (`synthetic`, `example.com`, `.test`);
- ставка вне 0–100% или интервал дохода некорректен.

`dataset_id` — отпечаток содержимого (SHA-256, 12 символов; не зависит от времени генерации). Он печатается в каждом файле (колонтитул PDF, слайды, свойства XLSX, шапка HTML) и в подписи документов бота. Одинаковый id = одни и те же данные.

## Честность отчёта
В каждом формате: плашка «демо-прототип», охват банков с причинами отсутствия данных (напр. Сбер — заблокирован), «ЛНР не подтверждена», предупреждение об устаревших данных при неудачной последней загрузке, методика и ограничения. Предложения «не для всех» отделены (штриховка/полый маркер).

## Выводы
Тексты «Главное» формируются программным правилом из чисел набора данных. Нейросеть пока не используется (этап 3).

## Известные ограничения
- Только светлая тема (документ ориентирован на печать); Plotly-графики HTML без статических PNG (Kaleido требует Chrome).
- Для PDF нужны системные библиотеки Pango и шрифты с кириллицей (в `Dockerfile` добавлены, образ не собирался).
- Проверка визуала выполнена по скриншотам HTML и конвертации PDF/PPTX/XLSX через LibreOffice; в PowerPoint/Excel файлы не открывались.
