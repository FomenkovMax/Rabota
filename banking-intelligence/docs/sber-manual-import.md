# Данные Сбербанка: ручной импорт публичных страниц

## Почему так
Загрузчик не получает сайт Сбера: `sberbank.ru` и `sberbank.com` (включая `robots.txt`) отвечают страницей WAF `user_blocked` (проверено 24.10.2026). Защиту мы не обходим. Легитимный путь — человек открывает **публичную** страницу в обычном браузере, сохраняет её, а система принимает файл с честной пометкой `origin=manual_import`.

> Только публичные страницы сайта/документы раскрытия. Внутренние банковские данные сюда не вносим и во внешние сервисы не отправляем.

## Что нужно сохранить
Для сравнения нужны страницы Сбера с условиями:
1. вклады (раздел «Вклады» на sberbank.ru);
2. накопительные счета (раздел «Накопительные счета»);
3. при желании — акции и «Информация о процентных ставках по вкладам» (раскрытие, часто PDF).

Точные URL я не придумываю — берите их из адресной строки браузера.

## Как сохранить
1. Откройте страницу в браузере (Chrome/Edge), дождитесь полной загрузки, **раскройте** блоки «Условия»/«Ставки» (то, что скрыто под спойлерами, может не попасть в файл).
2. Ctrl+S → тип «Веб-страница, только HTML» (лучше всего подходит) или «Веб-страница полностью».
3. PDF-документы сохраняйте как есть.
4. Запишите: URL из адресной строки и дату/время сохранения.

## Быстрый путь: пачкой (`import-dir`)
Если страниц много, не вводите команду на каждую.

1. Сохраните все страницы (Ctrl+S) в одну папку, например `imports/sber/`.
2. Создайте шаблон манифеста: `bankintel import-dir --dir imports/sber --init --category deposit`.
   Chrome/Edge при сохранении HTML обычно пишут в начало файла комментарий `saved from url=…` — тогда `url` подставится сам; остальное впишите из адресной строки.
3. Откройте `imports/sber/manifest.yaml` и заполните пропуски. Что можно задать:
   - `captured_at` — когда сохранено, с часовым поясом (`2026-10-24T12:00+03:00`) или `mtime` (время изменения файла — обычно это и есть момент сохранения);
   - `category` — `deposit`, `savings` или `promo` (общая или у каждой страницы);
   - `source_key` — по умолчанию из имени файла; `note` — заметка.
4. Проверьте без записи: `bankintel import-dir --bank sber --dir imports/sber --dry-run`.
5. Импортируйте: `bankintel import-dir --bank sber --dir imports/sber`.

Что гарантировано:
- проверки те же, что у `import-doc` (домен банка, пустой файл, формат, заглушка WAF/капчи, часовой пояс);
- плохая страница не мешает остальным: она получает `ERR` с причиной, код выхода ненулевой;
- повторный запуск безопасен: тот же файл пропускается (`--`), изменённый сохраняется новой версией;
- один `source_key` — одна страница; ключ, уже привязанный к другому URL, отклоняется;
- файлы вне папки (`../x.html`) и файлы больше 20 МБ не принимаются; лежащие в папке, но не указанные в манифесте файлы выводятся с пометкой `!!`.

В конце команда печатает фрагмент для `config/sources.yaml` (`mode: manual`, `status: active`) — добавьте его, чтобы источники не потерялись при `seed`.

## Как передать (по одной странице)
Положите файлы в репозиторий в `banking-intelligence/imports/sber/` (папка в `.gitignore` не добавлена намеренно: это публичные страницы; если файлы большие — скажите, договоримся иначе) или передайте мне любым доступным способом. Дальше:

```bash
bankintel import-doc --bank sber --source-key deposits \
  --url "<URL из адресной строки>" --category deposit \
  --file imports/sber/deposits.html --captured-at 2026-10-24T12:00+03:00 \
  --note "сохранено из Chrome, раскрыты блоки условий"
```

Команда отклонит файл, если: домен не принадлежит Сберу, файл пуст, формат не html/pdf, внутри страница блокировки/капчи, нет часового пояса в дате. Затем добавьте источник в `config/sources.yaml` (`mode: manual`, `status: active`) — команда напечатает готовый фрагмент.

## Что дальше (делаю я)
Адаптер Сбера пишется **по реальному сохранённому файлу** (структуры страницы я не знаю и не угадываю). `bankintel refresh` и `/refresh` обрабатывают импортированные документы без обращения к сети. В отчётах данные Сбера будут помечены как «ручной импорт от <дата>», а возраст данных — виден.

## Другие варианты (за пределами кода)
- Запросить у Сбера/партнёров разрешённый доступ (allowlist для User-Agent/IP) — решение за вами.
- Использовать официальные файлы раскрытия информации о ставках, если Сбер публикует их для скачивания.
