# Дополнительные корневые сертификаты

`russian_trusted_root_ca.pem` — «Russian Trusted Root CA» (Минцифры РФ), публичный сертификат (не секрет).

- Источник: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt (статика Госуслуг), получен 24.10.2026.
- SHA-256: `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`
- Действует до 27.02.2032.
- Независимо сверить отпечаток с другим официальным источником мы не смогли — **сверьте вручную** (раздел про сертификат Минцифры на gosuslugi.ru). Тест `test_ca_fingerprint_pinned` ловит подмену файла в репозитории, но не доказывает подлинность самого отпечатка.

Зачем: сайты Сбера, ПСБ, ВТБ подписаны этим CA, которого нет в стандартных наборах (без него — `tls_error`).

Ограничение доверия: сертификат подключается только в наш загрузчик (`EXTRA_CA_BUNDLE`), который ходит лишь по URL из `config/sources.yaml` (официальные домены банков). Системное хранилище не меняется. Не используйте этот файл как общий CA для других задач.
