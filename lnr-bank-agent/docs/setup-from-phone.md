# Установка агента на VPS с телефона

Время: 20–30 минут. Всё делается с телефона.

## Что понадобится

- **VPS в России** с Ubuntu 24.04 (подойдёт и 22.04): от 2 ГБ памяти (Chromium требовательный), 1–2 ядра, от 20 ГБ диска. Подойдёт любой хостинг с VPS в РФ, например Timeweb Cloud, Selectel, REG.RU, Beget. Тариф выбирай по этим параметрам.
- **Termius** — SSH-клиент для телефона (App Store / Google Play), бесплатной версии хватит.
- **Ключ GigaChat API** и **Telegram-бот** — пункт 4. Без них установка пройдёт, но GigaChat и уведомления не заработают.

## 1. Арендуй VPS

В личном кабинете хостинга создай сервер: ОС — **Ubuntu 24.04**, регион — Россия. После создания хостинг покажет (или пришлёт на почту) **IP-адрес** и **пароль root**.

## 2. Подключись через Termius

1. Termius → **Hosts** → **+** → **New Host**.
2. Address — IP сервера, Username — `root`, Password — пароль из письма.
3. Сохрани и нажми на хост. На вопрос о fingerprint ответь **Continue**.

Появится строка вида `root@...:~#` — ты на сервере.

## 3. Установи агента одной командой

Скопируй команду целиком и вставь в Termius (долгое нажатие → Paste):

```
curl -fsSL https://raw.githubusercontent.com/FomenkovMax/Rabota/ccr-d13b0862-srpe73/lnr-bank-agent/scripts/deploy.sh | bash
```

Займёт 5–10 минут. Скрипт:
1. ставит системные пакеты и часовой пояс Москвы;
2. создаёт пользователя `lnrbank` без прав администратора;
3. скачивает код, Python-зависимости и браузер Chromium;
4. ставит сертификат Минцифры со сверкой отпечатка;
5. настраивает запуск раз в неделю (пн 07:00 МСК).

В конце должно быть **«✅ Установка завершена»** и строки `OK` для пяти сайтов. Если видишь `✗` или `FAIL`, скопируй последние строки и пришли в чат.

## 4. Добавь ключи

Ключи вводятся командой, текст при вставке не отображается — так и задумано.

**GigaChat.** На developers.sber.ru зайди в личный кабинет GigaChat API, создай проект и скопируй **Authorization key**. Затем:

```
lnrbank-secret GIGACHAT_CREDENTIALS
```

**Telegram.**
1. В Telegram открой @BotFather → `/newbot` → придумай имя → скопируй **токен**:
   ```
   lnrbank-secret TELEGRAM_BOT_TOKEN
   ```
2. Открой своего нового бота и нажми **Start** — без этого бот не сможет тебе писать.
3. Узнай свой id через @userinfobot (пришлёт число):
   ```
   lnrbank-secret TELEGRAM_CHAT_ID
   ```

## 5. Первая проверка

```
lnrbank check
```

Команда открывает сайты четырёх банков, пытается выбрать ЛНР и делает скриншоты. **Скопируй весь вывод и пришли в чат** — по нему донастроим выбор ЛНР на каждом сайте.

Скриншоты лежат в `/home/lnrbank/Rabota/lnr-bank-agent/data/raw/check_ДАТА/`. Посмотреть их можно в Termius: **SFTP** → выбери сервер → открой папку → нажми на файл.

## Обновление

Когда я доработаю агента, повтори команду из пункта 3. Скрипт обновит код, настройки и ключи не тронет.

## Безопасность (5 минут, но важно)

- Смени пароль root: `passwd`.
- Ещё лучше — вход по ключу. В Termius: **Keychain** → **Generate Key** → потом в настройках хоста **Export to host**.
- Не показывай никому содержимое файла `.env` и токены.

## Если что-то пошло не так

Скопируй последние 20–30 строк из Termius и пришли в чат. Повторный запуск команды установки безопасен: уже сделанные шаги просто пропускаются.
