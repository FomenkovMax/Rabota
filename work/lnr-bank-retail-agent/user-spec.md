# User Spec: локальный агент сравнения розничных продуктов банков в ЛНР

## Problem

Нужно регулярно сравнивать условия розничных продуктов для физлиц у банков, работающих в ЛНР, и видеть, где Сбер сильнее конкурентов, а где отстаёт. Вручную это долго, а условия на сайтах зависят от выбранного региона: по умолчанию сайты показывают Москву.

Облачный ИИ-агент не подходит. Сайты Сбера, ВТБ, ПСБ и Т-Банка работают на сертификатах НУЦ Минцифры, а облачные браузеры им не доверяют (тест 05.10.2026: `prompts/lnr-bank-retail-agent/runs/2026-10-05_test-dostupa/run_log.md`). Поэтому агент работает локально, на машине с установленным сертификатом Минцифры.

## Users

- **Максим** — эксперт ПАО Сбербанк. Запускает агента, настраивает, читает результаты.
- **Руководство** — читает Excel, дашборд и выводы. Каждая цифра должна быть проверяемой.

## Scope

**MVP:**
- банки: Сбер (точка отсчёта), ВТБ, ПСБ, Т-Банк; поиск других банков в ЛНР (watchlist, без полного сравнения);
- блоки: сбережения (DEP), карты (CARD), кредиты (LOAN), ипотека (MTG), каналы и инфраструктура (CHANNEL);
- выходы: Excel и HTML-дашборд;
- алерты в Telegram;
- запуск по расписанию раз в неделю на Linux, macOS или сервере в РФ.

**Extension (второй этап):**
- блоки: повседневный банкинг (DAILY), инвестиции, пенсии и страхование (INV), сегментные предложения (SEG), сценарии TRF-1, TRF-2, CSH-1;
- Streamlit-дашборд, выгрузка CSV для BI, отчёт для руководства в docx;
- полное сравнение банков из watchlist.

## Requirements

- **US-1. Сбор условий.** Агент собирает условия продуктов блоков MVP у четырёх банков. Параметры по блокам — как в `<products>` системного промпта.
- **US-2. Привязка к ЛНР.** На каждом сайте агент выбирает ЛНР доступным способом: селектор региона, галочка в калькуляторе, региональные тарифы или подтверждение федеральных условий для жителя ЛНР. Проверяет, что регион применился, и записывает способ. Значения без подтверждённой привязки хранятся, но не участвуют в сравнении и выводах.
- **US-3. Проверяемость.** У каждого значения есть ссылка на официальный источник, дата сбора, способ привязки к ЛНР и цитата. Нет данных — «н/д» с причиной. Подстановки из других регионов, банков или прошлых срезов не допускаются. Агрегаторы и СМИ используются только как подсказка, где искать.
- **US-4. Типовые сценарии.** Для блоков MVP считаются сценарии DEP-1, DEP-2, SAV-1, DC-1, CC-1, CL-1, CL-2, CAR-1, MTG-1, MTG-2 из системного промпта. Где у банка есть калькулятор — по калькулятору, где нет — по опубликованным условиям формулами, с пометкой способа.
- **US-5. Позиция Сбера.** По каждому сценарию и ключевому параметру: место Сбера, отклонение от лучшего и от медианы, статус (лидер, в рынке, отстаёт, нет у Сбера, нет ни у кого), светофор «блок × банк». Пороги — из системного промпта.
- **US-6. Конвейер с историей.** Каждый запуск — срез с датой. Срезы копятся, новый сравнивается с прошлым, изменения сверх порогов становятся алертами.
- **US-7. Режимы и расписание.** Ручные режимы: проверка доступа, один блок, все блоки, обновление, пересборка выходов. Автоматический запуск раз в неделю.
- **US-8. Выходы MVP.** Excel с вкладками и графиками: сводка со светофором, продуктовые линейки, блоки, сценарии, позиция Сбера, изменения, качество данных, источники. HTML-дашборд одним файлом, который открывается без сервера и интернета.
- **US-9. Telegram.** После запуска приходит короткое сообщение: алерты, покрытие, главные выводы, ошибки. Файлы отчёта приходят следом. Об ошибке или блокировке сайта тоже приходит сообщение.
- **US-10. LLM.** Для разбора страниц и PDF-тарифов используется GigaChat API. Провайдер сменный.
- **US-11. Границы.** Только публичная информация. Агент не входит в личные кабинеты, не отправляет заявки и не вводит персональные данные. Капчи и блокировки не обходит: фиксирует их и сообщает. Внутренние данные Сбера не используются.
- **US-12. Продуктовые линейки.** Каталог продуктов каждого банка с отметкой доступности в ЛНР и матрица «продукт × банк».
- **US-13. Присутствие и инфраструктура.** Офисы (полноформатные, в МФЦ, мобильные) и банкоматы по городам ЛНР. Watchlist других банков в регионе.

## Acceptance Criteria

- **AC-1.** После проверки доступа по каждому банку видно: открывается ли сайт, выбран ли регион ЛНР и каким способом, а если нет — почему.
- **AC-2.** В Excel у каждого значения есть ссылка на источник, дата и способ привязки. Значения без подтверждённой ЛНР помечены и не участвуют в сравнении.
- **AC-3.** По каждому сценарию MVP в сводке видно место Сбера и отклонение от лучшего банка.
- **AC-4.** Если между срезами ставка изменилась на 0,25 п.п. или больше, это изменение есть на вкладке «Изменения» и в сообщении Telegram.
- **AC-5.** Агент сам запускается раз в неделю. Если запуск упал или сайт заблокировал доступ, приходит сообщение в Telegram.
- **AC-6.** HTML-дашборд открывается двойным кликом без интернета; фильтры, светофор и графики работают.
- **AC-7.** Excel открывается без ошибок, фильтры работают, графики на месте.

## Constraints

- Сертификат НУЦ Минцифры должен быть установлен на машине агента: нужен и сайтам банков, и GigaChat API.
- Платформа: основная — VPS в РФ с Ubuntu, управление с телефона через SSH; также Linux или macOS. Python.
- Нагрузка на сайты минимальная: последовательные запросы с паузами, раз в неделю.

## Testing Strategy (agreed for size L)

Unit-тесты расчётов и правил, интеграционные тесты на сохранённых страницах банков (офлайн), проверка извлечения LLM на эталонном наборе страниц, живые проверки на целевой машине.
