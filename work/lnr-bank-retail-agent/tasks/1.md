# Task 1: Каркас проекта, настройки и сертификаты

## Description

Создать самостоятельный Python-проект `lnr-bank-agent/` с полной структурой, всеми зависимостями MVP, CLI-заготовкой и загрузкой настроек. Добавить установку корня Минцифры и проверку TLS. Общие файлы (зависимости, схема `settings.yaml`, словарь `parameters.yaml`) создаются целиком здесь (D-20), чтобы параллельные задачи следующих волн их только читали.

Решения tech-spec: D-6, D-18, D-20.

## Acceptance Criteria

- [ ] `uv sync` ставит все зависимости MVP из стека tech-spec; `uv.lock` в репозитории.
- [ ] `lnrbank --help` показывает команды `check`, `run`, `build`, `notify`; нереализованные команды завершаются понятным сообщением и кодом ≠ 0.
- [ ] `config/settings.yaml` содержит все разделы: банки и домены, регион и город, блоки MVP, пороги и алерты, сценарии MVP, LLM (scope, model), браузер (headless, паузы), хранение (retention), watchlist, Telegram (без секретов).
- [ ] `config/parameters.yaml` описывает параметры всех блоков MVP: имя, единица, `better`, описание; имена — snake_case, условия входят в имя.
- [ ] Настройки валидируются pydantic: неверный тип или отсутствующий обязательный ключ → ошибка с указанием ключа.
- [ ] `scripts/install_certs.sh` скачивает корень с gu-st.ru, сверяет SHA-256 `D2:6D:…:CF:31` и при несовпадении завершается с ошибкой, ничего не устанавливая; ставит корень в системное хранилище (Ubuntu/Debian, macOS), в NSS DB (Linux) и собирает CA-бандл certifi + корень.
- [ ] `lnrbank check --tls-only` проверяет TLS к доменам банков и `api.giga.chat` с CA-бандлом; отключение проверки TLS нигде не используется.
- [ ] `.env.example` содержит `GIGACHAT_CREDENTIALS`, `GIGACHAT_SCOPE`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`; `.env` и `data/` в `.gitignore`.
- [ ] pre-commit: ruff, gitleaks, быстрые unit-тесты; `pre-commit run --all-files` проходит.
