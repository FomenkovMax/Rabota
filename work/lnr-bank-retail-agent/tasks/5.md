# Task 5: Браузерный движок, привязка к ЛНР и проверка доступа

## Description

Сделать слой браузера с вежливым сбором без обхода защит и движок `site_playbook` для выбора и проверки ЛНР. Заполнить playbook для четырёх банков по результатам теста доступа. Команда `lnrbank check` выполняет этапы 0–1: TLS, ключевая ставка, загрузка, привязка, присутствие банков, watchlist.

Решения tech-spec: D-2, D-7, D-21.

## Acceptance Criteria

- [ ] Один Chromium на запуск, контекст на банк (ru-RU, Europe/Moscow), последовательные загрузки с паузой 3–6 с, `headless` из настроек.
- [ ] robots.txt проверяется через `urllib.robotparser`; запрещённый путь → статус `blocked_by_robots`, без загрузки.
- [ ] Антибот-страница (маркеры вроде `TSPD`/`bobcmn`, пустая страница с JS-проверкой) или капча → статус `blocked`, скриншот; обхода, stealth-плагинов и подмены отпечатков нет.
- [ ] Движок playbook выполняет шаги (клик, выбор из списка, галочка, переход по URL), затем проверяет применение региона по условию из playbook и возвращает `region_method` + доказательство; при сбросе региона на следующей странице — повторная привязка.
- [ ] `site_playbook.yaml` заполнен для SBER, VTB, PSB, TBANK; для PSB использован Луганск (id 811307); для TBANK — путь `federal_confirmed`.
- [ ] Ключевая ставка ЦБ на дату берётся из таблицы `cbr.ru/hd_base/KeyRate/`.
- [ ] `lnrbank check` возвращает структурированный результат (банк, TLS, загрузка, привязка/причина, скриншот, watchlist по D-21), печатает таблицу и сохраняет `data/out/check_{дата}.json`. Запись в таблицу `banks` делает конвейер (задача 8), поэтому от хранилища задача не зависит.

## TDD Anchors

- Синтетическая страница с селектором города: движок выбирает «Луганск», проверка по шапке проходит → `selector`.
- Синтетическая страница с галочкой «новые регионы» → `calc_checkbox`.
- Страница, сбрасывающая регион после перехода → повторная привязка, затем успех.
- Страница с маркером TSPD → `blocked`.
- robots.txt с Disallow → `blocked_by_robots`.
- Парсер ключевой ставки на сохранённом HTML ЦБ → 14,00 на 05.10.2026.
