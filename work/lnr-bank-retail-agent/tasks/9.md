# Task 9: Выходы и доставка: Excel, HTML, Telegram

## Description

Сформировать Excel и самодостаточный HTML-дашборд по D-12 с защитой от внедрения по D-13. Отправлять в Telegram сводку запуска и файлы по D-15.

Решения tech-spec: D-12, D-13, D-15.

## Acceptance Criteria

- [ ] Excel: все вкладки из D-12, графики (ставки вкладов по срокам, ипотека по программам, выгода карт, Gap Сбера), закреплённые заголовки, автофильтр, форматы % и ₽, без объединённых ячеек в таблицах данных, кликабельные источники.
- [ ] Строки, начинающиеся с `=`, `+`, `-`, `@`, записываются как текст.
- [ ] HTML: один файл, Chart.js вложен (версия и SHA-256 зафиксированы), данные через `tojson`, autoescape; фильтры банк/блок/продукт/сценарий, KPI, светофор, графики, изменения, источники; работает без сети.
- [ ] Постоянный цвет каждого банка во всех графиках Excel и HTML.
- [ ] Telegram: `sendMessage` (алерты, покрытие, 3–5 выводов, ошибки; ≤ 4096 символов, длинное — частями), затем `sendDocument` с Excel и HTML; ошибка запуска или блокировка сайта — отдельное сообщение; токен маскируется в логах.
- [ ] `lnrbank notify --test` отправляет тестовое сообщение.

## TDD Anchors

- Значение `=HYPERLINK(...)` в Excel сохраняется как текст.
- Строка `</script><script>alert(1)</script>` из источника в HTML не исполняется (экранирована).
- Книга из фикстурной БД содержит все вкладки и графики, без объединённых ячеек в таблицах данных.
- Мок Telegram: длинная сводка разбита на части ≤ 4096; токен отсутствует в логах.

## Verification

- Verify-smoke: `lnrbank build` → файлы в `data/out/{snapshot}/`, openpyxl открывает книгу; `lnrbank notify --test` → сообщение пришло.
- Verify-user: Открыть Excel и HTML на телефоне и ПК без интернета, проверить светофор и графики; получить сообщение в Telegram.
