# Телеграм-бот: калории по фото холодильника

Присылаете боту фото содержимого холодильника — он отвечает списком продуктов
с калорийностью и подборкой блюд с КБЖУ и рецептом. В подписи к фото можно
написать пожелания: «на 4 порции», «без мяса», «что-нибудь быстрое».

Бот живёт на Vercel, поэтому к моделям он ходит из облака: блокировки в вашей
домашней сети на него не влияют, а на телефоне нужен только Telegram.

## Как поднять свой

1. **Создайте бота.** В Telegram напишите [@BotFather](https://t.me/BotFather) →
   `/newbot` → имя → адрес. Он выдаст токен вида `1234567:AA...`.
2. **Разложите проект на Vercel** (кнопка Deploy в панели или `vercel deploy`).
3. **Добавьте переменные окружения** в настройках проекта на Vercel
   (Settings → Environment Variables), затем Redeploy:

   | Переменная | Обязательна | Что это |
   | --- | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | да | токен от BotFather |
   | `OPENROUTER_API_KEY` | одна из двух | ключ [openrouter.ai/keys](https://openrouter.ai/keys), есть бесплатные модели |
   | `ANTHROPIC_API_KEY` | одна из двух | ключ Claude — точнее, но платно; если задан, используется он |
   | `TELEGRAM_SECRET` | нет | любая строка; бот будет отвергать чужие запросы к вебхуку |
   | `OPENROUTER_MODEL` | нет | своя модель или несколько через запятую; по умолчанию список бесплатных |
   | `ANTHROPIC_MODEL` | нет | по умолчанию `claude-opus-5` |
   | `FRIDGE_EFFORT` | нет | глубина расчёта Claude: `low`…`xhigh`, по умолчанию `medium` |
   | `FRIDGE_DISHES` | нет | сколько блюд предлагать, по умолчанию 4 |

4. **Откройте в браузере** `https://ваш-проект.vercel.app/api/setup` — страница
   проверит токен и ключ модели и сама зарегистрирует вебхук. Терминал не нужен.
5. Напишите боту `/start` и пришлите фото.

## Как устроено

```
api/telegram.js   вебхук: разбирает обновления, качает фото, отвечает разбором
api/setup.js      страница настройки: проверки и регистрация вебхука
lib/analyze.js    промпт, выбор провайдера, вызов модели, пересчёт сумм
lib/schema.js     JSON-схема ответа модели
lib/telegram.js   обёртка над Bot API
lib/format.js     оформление ответа под Telegram
```

Telegram ждёт ответ на вебхук считаные секунды, а разбор фото идёт десятки секунд,
поэтому бот отвечает `200` сразу, а работу продолжает через `waitUntil`. Фото из
альбома приходят разными обновлениями — они собираются по `media_group_id` и
разбираются вместе (до 4 штук за раз).

Провайдер выбирается по ключам: есть `ANTHROPIC_API_KEY` → считает Claude, иначе
`OPENROUTER_API_KEY` → бесплатная модель OpenRouter. Суммы калорий пересчитываются
на сервере: арифметике модели доверять не стоит.

Бесплатные модели на OpenRouter то появляются, то уезжают в платные, поэтому
их держат списком: бот идёт по нему сверху вниз, пока какая-нибудь не ответит.
Дневной лимит, отсутствующая модель, обрыв связи, неподдерживаемый `response_format`
(тогда повтор к той же модели без него) — всё это повод взять следующую, а не сдаться.
Актуальные бесплатные модели с картинками видно так:

```
curl -s https://openrouter.ai/api/v1/models |
  grep -o '"id":"[^"]*:free"'
```

## Точность

Калорийность оценивается по внешнему виду продуктов — это ориентир, а не измерение.
Ошибка в массе на глаз легко даёт ±20–30 %, а бесплатные модели путают похожие
продукты чаще Claude. Для медицинских задач взвешивайте продукты.
