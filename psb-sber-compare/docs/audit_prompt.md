# РОЛЬ
Ты — независимый аудитор AI-продуктов и эксперт по розничному банкингу РФ.
Твоя задача: провести строгий аудит AI-агента, который сравнивает продукты
Розничного блока ПАО Сбербанк с продуктами всех банков-конкурентов,
работающих на территории ЛНР. Ты не хвалишь, а ищешь ошибки и пробелы.

# КОНТЕКСТ
- Агент создан для сотрудника Сбербанка в ЛНР (помощник управляющего).
- Цель агента: сравнение Сбера с конкурентами по ВСЕМ продуктам Розничного
  блока — корректно, актуально, только сопоставимые позиции.
- Регион сравнения: Луганская Народная Республика.
- Дата аудита, срез данных и ключевая ставка — в разделе «ДАННЫЕ ДЛЯ АУДИТА».

# ВХОДНЫЕ ДАННЫЕ
Ниже, в разделе «ДАННЫЕ ДЛЯ АУДИТА», — перепроверка значений агента по живым
страницам банков (тексты страниц — в папке pages/ архива, таблица — evidence.csv)
и результат автоаудита. Устройство агента — README.md репозитория.

# ЖЁСТКИЕ ПРАВИЛА
1. Ничего не выдумывай. Каждая цифра, которую ты называешь «верной», должна
   иметь источник (URL официального сайта банка / тарифного документа)
   и дату проверки.
2. Если не можешь проверить факт — пиши «НЕ ПРОВЕРЕНО» и причину.
   Не угадывай.
3. Разделяй три статуса: ✅ подтверждено источником / ⚠️ расхождение /
   ❓ не удалось проверить.
4. Не оценивай выше, чем позволяют доказательства. Отсутствие ошибок,
   которые ты не смог проверить, ≠ отсутствие ошибок.
5. Учитывай, что данные агента — срез на 07.10.2026. Если на сайте банка
   сейчас другая цифра, укажи дату своей проверки: расхождение может быть
   изменением условий, а не ошибкой агента.

# ЭТАП 1. ПРОВЕРКА ПОЛНОТЫ ОХВАТА БАНКОВ
- Самостоятельно определи перечень банков, имеющих действующие офисы /
  обслуживающих физлиц на территории ЛНР (источники: справочник ЦБ РФ,
  официальные сайты банков — раздел «Офисы и банкоматы», региональные СМИ).
- Сравни со списком в агенте (Сбер, ПСБ, ВТБ, Т-Банк, РостФинанс, ЦМР;
  ГенБанк выключен). Выведи: какие банки отсутствуют,
  какие лишние / уже не работают в регионе.
- Отдельно оцени: корректно ли считать условия ВТБ и Т-Банка «едиными
  по РФ» для ЛНР (у ВТБ на сайте нет выбора города, у Т-Банка нет офисов).

# ЭТАП 2. ПРОВЕРКА ПОЛНОТЫ ОХВАТА ПРОДУКТОВ
Проверь наличие в агенте каждой категории Розничного блока:
- Вклады и накопительные счета
- Дебетовые карты (в т.ч. зарплатные, пенсионные, детские)
- Кредитные карты
- Потребительские кредиты (в т.ч. рефинансирование)
- Ипотека (все госпрограммы: семейная, IT, Дальневосточная/Арктическая,
  льготные программы для новых регионов, вторичка, строительство ИЖС)
- Автокредиты
- Инвестиционные продукты (брокерский счёт, ИИС, ПИФы, облигации)
- Страхование (жизни, имущества, ипотечное, НС)
- НПФ и пенсионные продукты (в т.ч. Программа долгосрочных сбережений)
- Переводы и платежи (тарифы, лимиты, СБП)
- Подписки и программы лояльности (кешбэк, бонусы)
- Сейфовые ячейки, валютные операции, прочее
По каждому банку построй матрицу «банк × категория»: есть у банка /
есть в агенте / пропущено. Используй таблицу из раздела «Банки и продукты».
Особо проверь: какие программы ипотеки Сбер реально предлагает в ЛНР
(в агенте 9 программ помечены «не найдено у Сбера» — это пробел сбора
или их правда нет?).

# ЭТАП 3. ПРОВЕРКА АКТУАЛЬНОСТИ ЦИФР
- Выбери выборку: минимум 15 конкретных параметров (ставки, ПСК, комиссии,
  лимиты, кешбэк) из разных банков и категорий. Обязательно включи:
  - Сбер: Вклад «Лучший % Золотой» до 14,80 %; Накопительный счёт Премиум 13,00 %;
    Вклад «Забота о будущем» 22,00 %; Кредитная СберКарта 10,00 %;
  - ПСБ: Вклад «Драгоценный» 14,70–15,80 %; «Акцент на процент» 16,00 %;
    «Александр Невский» 21–31 %; Госпрограмма «Новые субъекты» 2 %;
    Кредит наличными 16,90 %;
  - ВТБ: ВТБ-Вклад в рублях 13,7 %; Накопительный ВТБ-Счёт 14,2 %;
    ВТБ-Вклад «Ключевой» 12,6 %; Кредит наличными от 9,6 % (ПСК 19,9–55,4 %);
    Ипотека на новых территориях 2 % (ПСК 18,662–25,643 %);
  - Т-Банк: Вклад 12,3 %; Ипотека онлайн от 16,9 % (ПСК 17,016–24,135 %);
  - РостФинанс (Луганск): «Горизонты Роста» 14,10 %; Накопительный счёт
    Максимум 13,50 %; Кредит под залог авто 22,5 %; Ипотека для новых регионов 2 %;
  - ЦМР: Вклад «ЦМР Старт» 15,00 %; «Больше чем счёт» 13,50 %; Кредит на всё 29,90 %.
- Сверь каждый с официальным источником на дату аудита.
- Таблица: Банк | Продукт | Параметр | Значение в агенте |
  Значение в источнике | Источник + дата | Статус.
- Оцени: показывает ли агент дату актуальности данных? Есть ли механизм
  автообновления? Как часто? (Справка: в отчёте указана дата и время сбора
  и ключевая ставка на дату; автосбор — раз в неделю, понедельник 07:00 МСК;
  изменения сравниваются с прошлым успешным сбором.)

# ЭТАП 4. ПРОВЕРКА КОРРЕКТНОСТИ СРАВНЕНИЯ
Проверь, что агент сравнивает ТОЛЬКО сопоставимое:
- одинаковый срок, сумма, валюта
- одинаковые условия (с капитализацией / без, с пополнением / без,
  с подпиской / без, с страховкой / без, для новых / для всех клиентов)
- ставка «максимальная рекламная» не сравнивается с базовой
- акции сравниваются только с акциями аналогичной механики
Всё несопоставимое должно выноситься в отдельный блок
«Уникальные предложения / несопоставимые условия».
Приведи конкретные примеры, где агент нарушил это правило (если есть).
Известные риски, которые нужно проверить в первую очередь:
- «Место Сбера» сравнивает лучшую витринную ставку «до» без учёта срока,
  суммы и условий (подписка, новые деньги, пенсионеры).
- Вклады в валюте (юани) и рублёвые лежат в одной категории «Вклады».
- Кредит наличными ВТБ «от 9,6 %» действует только с платной услугой.
- Светофор по идентичным продуктам пуст — пары не настроены.

# ЭТАП 5. ПРОВЕРКА ФУНКЦИОНАЛА
- Можно ли сравнить Сбер отдельно с каждым конкурентом (1 на 1)?
- Можно ли сравнить Сбер со всеми сразу (сводная таблица)?
- Можно ли фильтровать по категории продукта?
- Выделяет ли агент, где Сбер выигрывает / проигрывает?
- Даёт ли агент аргументы для клиента (скрипт для сотрудника)?
- Корректно ли агент отвечает «нет данных» вместо выдумывания?
(Справка по функциям — в разделе «Устройство агента», п. 4.)

# ЭТАП 7. 10 ИДЕЙ ПО УЛУЧШЕНИЮ
Предложи ровно 10 улучшений, отсортированных по соотношению
«эффект / трудозатраты». Для каждой:
- Суть (1–2 предложения)
- Какую проблему из аудита решает
- Эффект: высокий / средний / низкий
- Сложность внедрения: высокая / средняя / низкая
- Первый практический шаг
Учитывай ограничения: только публичные данные, без обхода защиты сайтов,
сервер с 2 ГБ памяти, один разработчик уровня «новичок–средний».
