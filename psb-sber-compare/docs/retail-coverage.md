# Проверка полного розничного каталога и Луганска

Охват включает вклады, счета, карты, кредиты, ипотеку, страхование, инвестиционные услуги, ПДС/НПФ, переводы, валюту, ячейки, премиальные пакеты и лояльность. По уточнению заказчика включаются также отдельные акции и облигации из каталогов банков.

## Что подтверждают показатели

Количество найденных продуктов не является процентом полноты. Ссылка на раздел означает обнаруженный источник, но не прочитанные условия. Наличие офиса подтверждает присутствие банка, но не доступность каждого продукта. В таблице отдельно считаются продукты с доказательствами по ЛНР и по городу Луганску; город является подмножеством региона.

Если свидетельства о выборе региона отсутствуют, применяется `not_confirmed`. Импорт файла сам по себе не является доказательством выбора региона. Общероссийские условия и локальный профиль банка не допускают продукт в региональный рейтинг автоматически. Подтверждение города хранится с конкретным продуктом.

Акции и облигации сопоставляются только по однозначному ISIN с проверенной контрольной цифрой. Алгоритм соответствует описанию [ANNA](https://anna-web.org/identifiers/). Это проверка формата идентификатора, не проверка текущего допуска бумаги к торгам. Купон и историческая доходность не превращаются в банковскую процентную ставку. Без ISIN страницы не склеиваются по названию эмитента. Страница бумаги и выбранный город банковского сайта не доказывают доступность сделки в Луганске.

## Условия завершения проверки

Для каждого банка нужны полный исходный каталог, отсутствие необработанной очереди, разбор ошибок чтения и проверка категорий, для которых обнаружены только ссылки. У каждого продукта нужны дата, источник, условия и региональное основание. Нельзя объявлять 100% при недоступных источниках, неизвестных страницах или неподтверждённых региональных условиях.

Полный обход без лимита задаётся `max_pages: 0`. При продолжении используются `resume_urls` и `skip_urls`; адреса продолжения не считаются витринами. Сохраняются тексты предыдущих проходов и прежние продукты со своей датой. Необходимо учитывать отдельно ошибки чтения: пустая очередь не означает успешного чтения всех страниц.

## Проверки без повреждения рабочих данных

Тесты браузерных адаптеров сохраняют артефакты во временные каталоги pytest. На сервере тестовый контейнер запускается без рабочих томов `data` и `config`. Перед обновлением создаются резервные копии базы SQLite и текстов страниц. Одновременные сборщики не должны независимо записывать итоговые срезы в одну рабочую базу.

## Незакрытые внешние проверки

Сайт Генбанка при проверке с сервера 13.11.2026 вернул блокировку доступа. Это не отсутствие продуктов. Для проверки каталога нужен доступный официальный источник или сохранённые страницы банка; региональные условия каждого продукта проверяются отдельно. По остальным банкам дочитывание и проверка пропусков продолжаются. Этот документ не удостоверяет полноту каталога.
