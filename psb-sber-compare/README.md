# Сравнение розничных продуктов: ПСБ и Сбер (ЛНР)

Еженедельный сбор условий по розничным продуктам ПАО «Банк ПСБ» с сайта
psbank.ru, сопоставление с выгрузкой по Сберу и HTML-отчёт со светофором,
дельтами ставок, историей за год и списком действующих акций.

---

## Что удалось выяснить про сайт ПСБ

Перед разработкой сайт был проверен на предмет защиты. Результаты:

| Проверка | Результат |
|---|---|
| Капча, Qrator, Cloudflare, DDoS-Guard | Не обнаружены. Страницы отдаются обычным HTTP-запросом |
| Лимит частоты запросов | **Есть.** При обходе ~120 страниц с паузой 1 с сайт начинает отвечать 403. Это не блокировка: доступ возвращается секунд через двадцать |
| robots.txt | Раздел `/personal/**` не запрещён |
| Где лежат данные | В теге `<script id="serverApp-state">` — JSON примерно на 900 КБ (сайт на Angular Universal) |
| Прямой REST API `/back/api/v1/...` | Отдаёт **403**: WAF требует подписанные заголовки `__dp_rsa` / `__dp_id` |
| TLS-сертификат | Выпущен НУЦ Минцифры («Russian Trusted Root CA») |
| Региональность | Управляется cookie `geoId`. Проверено: ставки по вкладам в Москве и Луганске **действительно различаются** |

**Вывод: агент-парсер «в обход защиты» не нужен.** Данные забираются обычным
`requests` и разбором JSON — без headless-браузера, без эмуляции и без
обращения к закрытому API. Это и быстрее, и устойчивее к редизайну сайта.

Единственное, что требует аккуратности, — темп обхода. Пауза между запросами
вынесена в настройки (`psb.pause`, по умолчанию 1,5 с), а на 403 и 429
инструмент выжидает и повторяет попытку, а не падает.

```bash
cd psb-sber-compare
python -m venv .venv

# Windows
.venv\Scripts\activate

source .venv/bin/activate

pip install -r requirements.txt
```

### Сертификат НУЦ Минцифры

Сайт ПСБ использует сертификат Минцифры, которого нет в стандартном наборе
Python. Без него `requests` падает с `CERTIFICATE_VERIFY_FAILED`.

Корневой сертификат уже лежит в `certs/russian_trusted_ca.pem` и
подхватывается автоматически — делать ничего не нужно. Если сертификат
устареет, скачай свежий с https://www.gosuslugi.ru/crt и положи в ту же
папку рядом с существующим.

Проверка верности настройки:

```bash
python run.py check
```

Ожидаемый вывод:

```
Регион запроса: Луганск (cityId 811307)
[ОК] Страница получена  1 246 340 символов
[ОК] Каталог построен: 306 страниц
[ОК] Регион на странице: Луганск определён
```

## Быстрый старт

```bash
python run.py check              # 1. проверить доступ к сайту
python run.py collect --open     # 2. собрать и открыть отчёт
```

В Visual Studio Code всё это заведено в **Run and Debug** (F5) — пять
готовых конфигураций от «Проверка доступа» до «История запусков».

## Команды

| Команда | Что делает |
|---|---|
| `python run.py check` | Проверяет доступность сайта, сертификат и определение региона |
| `python run.py collect` | Полный прогон: сбор → сравнение → отчёт. Основная команда |
| `python run.py suggest` | Черновые пары продуктов для ручной проверки. Берёт данные последнего сбора; `--fresh` заставит обойти сайт заново |
| `python run.py report` | Пересобирает отчёт из последних данных, **без похода на сайт** |
| `python run.py history` | Показывает прошлые запуски и число изменений |

Флаги: `--open` открыть отчёт в браузере, `-v` подробный лог,
`--fresh` (для `suggest`) обойти сайт заново вместо использования последнего сбора.

## Данные по Сберу

Положи выгрузку в `data/sber.xlsx`. Поддерживаются `.xlsx`, `.csv`, `.json`.
Путь меняется в `config/settings.yaml` → `sber.source`.

Шаблон с нужными колонками: **`data/sber_example.xlsx`**.

Колонки распознаются по названию, регистр и точная формулировка не важны:

| Поле | Как может называться |
|---|---|
| Ключ | `Ключ`, `Код`, `ID`, `Артикул` |
| Название | `Продукт`, `Название`, `Наименование` |
| Категория | `Категория`, `Тип`, `Группа` |
| Ставка | `Ставка`, `Процентная ставка`, `Ставка, %` |
| ПСК | `ПСК`, `Полная стоимость кредита` |
| Сумма | `Сумма`, `Лимит`, `Сумма кредита` |
| Срок | `Срок`, `Срок кредита`, `Срок вклада` |
| Акция | `Акция`, `Спецпредложение`, `Промо` |
| Ссылка | `Ссылка`, `URL`, `Источник` |

Нераспознанные колонки не теряются — они попадают в карточку продукта как
дополнительные условия. Если обязательную колонку распознать не удалось,
инструмент **скажет об этом в логе**, а не подставит правдоподобное значение.

## Сопоставление продуктов

Это самое важное место, и оно намеренно ручное.

В отчёт попадают **только пары из `config/product_map.yaml`**. Автоматический
матчинг по названию работает как подсказка и формирует черновик, но сам в
отчёт не идёт: «Кредит наличными» ПСБ и «Потребительский кредит» Сбера похожи
по названию, но могут отличаться условиями допуска. Цена ошибки — неверная
цифра в отчёте у руководителя.

Порядок работы:

```bash
python run.py suggest
# → data/pairs_suggested.yaml — черновик, отсортирован по похожести
```

Проверяешь глазами, переносишь подтверждённые пары в `config/product_map.yaml`.

```yaml
pairs:
  - psb: /personal/loans/kredit-nalichnymi
    sber: sber_cash
    label: Кредит наличными
    category: Кредиты
```

> **Важно про `category`.** Для «Вклады», «Накопительные счета» и
> «Долгосрочные сбережения» выгодой клиента считается ставка **выше**,
> для кредитных продуктов — **ниже**. Без правильной категории светофор
> покрасит вклады наоборот.

---

## Светофор

Дельта считается как **ставка Сбера минус ставка ПСБ**, с позиции Сбера:

| Цвет | Значение | Условие по умолчанию |
|---|---|---|
| 🟢 Выигрываем | Сбер выгоднее клиенту | дельта в пользу Сбера, больше 0,5 п.п. |
| 🟡 Паритет | Разница несущественна | менее 0,5 п.п. в любую сторону |
| 🔴 Проигрываем | ПСБ выгоднее клиенту | отставание от 1,0 п.п. |
| ⚪ Нет данных | Сравнение невозможно | не извлеклась ставка или нет пары |

Пороги меняются в `config/settings.yaml` → `thresholds`.

## Что считается изменением

Сравнивается с предыдущим успешным сбором:

* **Движение ставки** — сдвиг от 0,25 п.п. помечается как важный;
* **Новая акция** и **завершение акции** — важное;
* **Новый продукт** и **уход продукта** из линейки;
* **Правка условий** в тарифной таблице (сумма, срок, ПСК, требования).

## Ограничения, о которых нужно знать

1. **Ставка «от»** — это минимальная заявленная ставка с сайта. Фактическая
   определяется индивидуально, поэтому в отчёте есть дисклеймер и ссылка
   на первоисточник по каждому продукту.
2. **Кредиты ПСБ не дифференцируются по региону** — проверено, условия в
   Москве и Луганске совпадают. Региональность реально работает по вкладам.
3. **Часть страниц — разделы-лендинги**, а не продукты. Такие страницы в
   отчёт не попадают: фильтр отсекает всё, где нет ни одного условия.
4. **Изменение вёрстки сайта** сломает сбор. Диагностика: `python run.py check`
   покажет, что каталог пуст или состояние не найдено.

## Тонкости, которые заложены в логику

### Какую границу ставки сравниваем

Банк рекламирует кредит как «ставка **от** 16,9%», а вклад — как «**до** 13,8%».
Клиент сравнивает именно эти витринные цифры, поэтому:

* по кредитным продуктам сравнивается **нижняя** граница диапазона;
* по вкладам, накопительным счетам и долгосрочным сбережениям — **верхняя**.

Категория берётся из `product_map.yaml`, так что ошибка в ней приведёт
к сравнению разных концов диапазона. Проверяй категорию при заполнении пар.

### Ставки по вкладам собираются из таблиц

У вкладов условия лежат не в тарифной таблице, а в сетке «срок × сумма».
Здесь две ловушки, обе обойдены:

* **Минимальная гарантированная ставка (МГС)** считается по другим правилам
  и всегда ниже витринной. Она отсеивается на уровне строки и колонки, а не
  по заголовку таблицы: в шапке ПСБ нередко названы обе метрики сразу, и
  фильтр по заголовку выбросил бы таблицу целиком вместе со ставками.
* **Колонка со ставками определяется по содержимому, а не по названию.**
  У одного вклада колонки подписаны «Срок вклада 32 дня», у другого просто
  «32 дня», а шапка «СУММА/СРОК ВКЛАДА» ложно срабатывает на слово «срок»
  и выдаёт колонку сумм за колонку ставок.

К витринной ставке отчёт всегда показывает условия, при которых она
достигается. Это не украшение: «31% годовых» и «31% на 32 дня при сумме
до 50 000 ₽» — принципиально разные предложения, и без второй половины
акционный вклад сравнивается с обычным срочным как равный.

### Узлы карты сайта без страниц

Карта сайта — это дерево CMS, часть узлов служебные и страницы под ними нет.
Такие адреса дают 404, инструмент их тихо пропускает и пишет в лог итоговое
число. Это норма, а не сбой.
