# 五条 悟 — GOJO SATORU

Интерактивная страница-трибьют Сатору Годзё, построенная по структуре
[itachi-страницы](https://meghamittal0920.github.io/itachi/): прелоадер, зерно/виньетка,
фиксированный chrome с боковыми рельсами, scroll-scrub первого акта, второй акт с
глазами, следящими за курсором, сетка техник, цитата, футер.

Ключевое отличие от референса: **там графика — это две последовательности JPEG-кадров
(71 + 51), здесь кадров нет вообще**. Каждый кадр обоих актов рисуется процедурно на
canvas, поэтому в репозитории ноль бинарных ассетов, а картинка масштабируется под
любую плотность пикселей.

## Запуск

Статика без сборки — достаточно любого http-сервера:

```bash
cd gojo && python3 -m http.server 8099   # → http://127.0.0.1:8099/
```

## Структура

```
index.html   разметка: прелоадер, chrome, четыре акта, футер
style.css    палитра (синий 蒼 / красный 赫 / фиолетовый 茈), раскладка, реврилы
main.js      вся графика и интерактив (см. ниже)
qa/shot.cjs  скриншоты на 13 позициях скролла × 2 вьюпорта + лог консоли
```

## Что делает main.js

| Блок | Что это |
|---|---|
| `drawEye()` | один примитив глаза: веки-безье (верхнее круче нижнего), радужка со штриховкой, шесть меток «六眼» на кольце, зрачок, блик. Используется обоими актами |
| Акт I `renderScrub` | сцена как функция прогресса секции: повязка из девяти лент разматывается → веки открываются → кольца «無下限» сходятся геометрической прогрессией → синяя и красная сферы сталкиваются в 虚式「茈」 |
| Акт II `renderEyes` | те же глаза, зрачки следят за курсором с инерцией; на тач-устройствах взгляд ведёт сам себя. Readout внизу слева показывает координаты взгляда |
| `renderHem` / `renderMotes` | частицы呪力 по нижней кромке вьюпорта и мошки над первым актом |
| `strike()` | разряд: генерируется ломаный SVG-path с ответвлениями + вспышка |
| Курсор | кольцо догоняет указатель с затухающим коэффициентом — сходится, но не долетает (шутка про Бесконечность) |
| `renderGhost` | шлейф курсора в третьем акте, кольцевой буфер точек |
| `audio` | звук синтезируется WebAudio (два расстроенных осциллятора под lowpass + LFO), аудиофайлов нет |

## Ограничения

- Шрифты тянутся с Google Fonts — при офлайне подставляются системные.
- `prefers-reduced-motion: reduce` отключает разряды, частицы, кастомный курсор и
  дрейф; scroll-scrub остаётся, потому что это прямая реакция на скролл пользователя.
- На `hover: none` кастомный курсор скрыт, взгляд во втором акте анимируется сам.

## QA

```bash
node qa/shot.cjs http://127.0.0.1:8099/ qa/screens
```

Кладёт кадры `desktop-000…096.png` и `mobile-*.png` в `qa/screens/` и печатает
ошибки консоли.
