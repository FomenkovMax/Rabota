# Презентация «Неночь» (Nevernight)

Разбор романа Джея Кристоффа «Неночь» — 13 слайдов, тёмная готика, без спойлеров,
формат под публичное выступление (крупные тезисы на слайдах, подробности в заметках докладчика).

- `nenoch-presentation.pptx` — готовый файл.
- `build.js` — генератор (pptxgenjs + react-icons).

## Пересобрать

```bash
npm install pptxgenjs react-icons react react-dom sharp
node build.js          # → nenoch.pptx
```

## Источники фактов

Награды, оценки и выходные данные сверены по ru.wikipedia.org, fantlab.ru и livelib.ru.
Прямые цитаты из книги в презентацию намеренно не включены — на слайде 12 приведены
только оценки и претензии читателей, а «сноска» на слайде 11 подписана как пример
оформления приёма, а не цитата.
